# HIV Risk Assessment System

A Prolog-based expert system that assesses HIV risk through interactive questioning and provides personalized recommendations.

---

## Medical Disclaimer

> **This is an educational tool only. Not for medical diagnosis. Always consult healthcare professionals.**

---

## Quick Start

```prolog
?- [hiv_advisory].
?- start_hiv_diagnosis.
```

---

## Features

- Interactive Q&A about risk factors and symptoms
- Risk level classification (Low/Moderate/High)
- Personalized health recommendations
- Dynamic assessment based on user responses

---

## Assessed Factors

**Risk Factors:**  
- Unprotected sex
- Multiple partners
- Shared needles
- Blood transfusion
- Parent with HIV

**Symptoms:**  
- Fever
- Fatigue
- Weight loss
- Night sweats
- Rash
- Swollen lymph nodes

---

## Risk Levels

- **Low:** Less than 2 total factors → Preventive measures  
- **Moderate:** 2-3 factors → Consult doctor and consider testing  
- **High:** More than 3 factors → Immediate medical attention

---

## Usage

Answer yes/no questions about your experiences.  
System calculates risk and provides advice.
